Conexión con Cloudflare

Así las webs y los códigos QR encuentran este servidor en una dirección fija. Se hace una sola vez.

Llave del Worker

••••••••••••••••

  1. En Cloudflare abre Workers & Pages → scan-bar → Settings → Variables and Secrets.
  2. Add → tipo Secret, nombre SCANBAR_PROXY_KEY, valor: la llave de arriba → Deploy.
  3. Pega aquí arriba la dirección de ese Worker (https://scan-bar.<tu-cuenta>.workers.dev) y guarda.
